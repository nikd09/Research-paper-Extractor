# Seat Recliner AI Knowledge Extraction

Automated engineering literature extraction pipeline using Gemini.

## Project site

`site/` holds the project site for the engine — the verification model, the architecture,
the domain-pack question, the seat recliner case study, the engineering log, cost and ops,
and the known limits. See [`site/README.md`](site/README.md) for local dev, build and
deploy. It ships to GitHub Pages on any push to `main` that touches `site/`.
